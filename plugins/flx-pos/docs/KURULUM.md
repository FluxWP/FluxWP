# Flux POS kurulumu

1. WordPress 6.5 veya üzeri ve PHP 8.1 veya üzeri sürüm kullanın. Ödeme almak için WooCommerce 8.0 veya üzeri sürümü kurup etkinleştirin.
2. Flux GraphQL eklentisini kurup etkinleştirin. WordPress yönetiminde **Eklentiler › Yeni eklenti ekle › Eklenti yükle** yolundan Flux POS ZIP dosyasını yükleyin ve etkinleştirin.
3. **POS › POS hesapları › POS ekle** yolunu izleyin. Sağlayıcınızı seçin, hesap bilgilerini girin ve test modunda bağlantıyı sınayın.
4. **Ödeme yöntemleri** sekmesinde yöntemleri açın, sıralayın ve ödeme önizlemesini kontrol edin. Gerekirse **Ayarlar** sekmesinde varsayılan hesabı ve para birimi yönlendirmelerini seçin.

Mevcut kurulumda ZIP dosyasını yükleyip WordPress'in mevcut sürümü değiştirme seçeneğini kullanın. Hesaplar, ayarlar ve işlem kayıtları veritabanında kalır.
