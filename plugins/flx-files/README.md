# Flux Files

**English** · [Türkçe](README.tr.md)

A modern file manager for WordPress administrators, with AI and MCP support.

- **Browse** the site files in a list or grid, search names and contents, right-click for every action, drag and drop to upload whole folders (chunked, past the hosting upload limit) or to move files.
- **Edit** code in a tabbed editor with a file tree, syntax highlighting, find and replace and a version history with diffs.
- **Stay safe**: the manager never leaves the WordPress folder, protected files cannot be deleted, deletes go to a trash, every save keeps the previous version and every change is logged in Activity.
- **Flux AI**: explain a file or ask AI for a change and review the diff before applying. AI chat and MCP clients can list, read and search files; changes need approval, and secret files such as `wp-config.php` are never shared.
- **Document library**: share an uploads folder on the site with `[flx_files folder="wp-content/uploads/documents"]`.

Requires WordPress 6.4+ and PHP 7.4+. Flux AI & MCP is optional.
