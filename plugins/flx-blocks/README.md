# Flux Block Editor

A block toolkit for the WordPress editor: row and column layouts, advanced heading, buttons, icons, info boxes,
gallery, tabs, accordion, tables, forms, a header and menu builder and more, all as `flx/*` blocks.

- **Layout blocks.** Row layout with responsive columns, sections, spacer/divider, show more, table of contents.
- **Content blocks.** Advanced heading, buttons, icon and icon list, info box, image, gallery, testimonials,
  countdown, count up, progress bar, video popup, Lottie, maps (no API key needed), posts and search.
- **Forms.** Simple and advanced form blocks, form post type, spam protection through Flux reCAPTCHA.
- **Style Library.** Design tokens (colours, typography, spacing, radius, shadow) and block presets; follows the
  FluxWP theme palette and dark mode.
- **No remote calls.** Lottie player, video icons and Google Fonts are served from your own site.
- Multilingual sites: block text is translated through the FluxWP theme on `/en/` and other language pages.
