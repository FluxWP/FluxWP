FluxWP block editor toolkit: layout, design and form blocks for the WordPress block editor.

== Description ==

Flux Block Editor adds rows, columns, sections, advanced headings, buttons, galleries, tabs, accordions, forms and more to the WordPress block editor. It is part of the FluxWP package family and works with the FluxWP theme and presets.
